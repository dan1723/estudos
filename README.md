# Caderno de estudos

Aqui ficam os meus **estudos de programação**. Os projetos que faço para clientes ficam separados, como cases de portfólio, no [meu perfil](https://github.com/dan1723).

## Como este repositório funciona

Cada assunto novo ganha uma pasta, com as anotações, os exercícios e o projeto de prática. Exemplo de organização:

```
estudos/
├── react/              ← próximo: refazer o cardápio de restaurante do zero
├── javascript/
├── php-laravel/
└── banco-de-dados/
```

Em cada pasta, um `README.md` conta o que estudei, o que aprendi e o que ainda falta.
